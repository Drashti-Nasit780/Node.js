# 🛒 E-Commerce Platform API (Node.js Practical Exam Project)

This project is a backend-based **E-Commerce Platform** developed using **Node.js**, **Express.js**, and **MongoDB Atlas** following the **MVC Architecture**.

The system provides secure authentication, role-based authorization, multi-user product management, and category management using REST APIs tested via Postman.

---

## 🚀 Features

- MVC Architecture
- JWT Authentication
- Cookie-Based Login System
- Role-Based Access Control (Admin & User)
- Multiuser Product Support
- Product CRUD Operations
- Category CRUD Operations
- MongoDB Relationships using Populate
- Protected Routes using Middleware
- API Testing using Postman

---

## 🧰 Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JSON Web Token (JWT)
- bcryptjs
- cookie-parser
- dotenv
- Postman
